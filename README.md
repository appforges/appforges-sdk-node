# @appforges/sdk

Official AppForges TypeScript SDK — generated by [sdk-gen](https://github.com/appforges/sdk-gen) from the
OpenAPI spec. Supports Node.js 18+, Bun, browsers and Web API runtimes.

## Install

```bash
npm i @appforges/sdk
```

## Quick start

```ts
import { AppForges } from "@appforges/sdk";
import { BearerAuth } from "@appforges/sdk/runtime/auth/bearer";
import { AppForgesError } from "@appforges/sdk/runtime/errors";

const client = new AppForges({
  baseURL: "https://api.appforges.com",
  auth: new BearerAuth(process.env.APPFORGES_ACCESS_TOKEN!),
});

try {
  const me = await client.users.getProfile();
  console.log(me);
} catch (error) {
  if (error instanceof AppForgesError) {
    console.error(error.httpStatus, error.requestId, error.message);
  }
  throw error;
}
```

- `appforges.creative.v1` 0.60.0
- `appforges.iam.v1` 0.60.0
- `appforges.pinpage.v1` 0.60.0

Wire payloads are snake_case and pass through untouched; see the API
reference at https://developer.appforges.com.
The profile endpoint requires an OAuth access token representing a user.
For staging, set baseURL to https://api-staging.appforges.com.
